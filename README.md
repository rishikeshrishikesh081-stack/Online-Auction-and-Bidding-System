# Online Auction and Bidding System

## Project Description
The Online Auction and Bidding System is a web-based application that allows users to participate in online auctions, place bids on products, and view auction results. It includes an admin dashboard to manage users, products, and bidding activities, along with a fraud alert module to identify suspicious bidding behavior.

## Features
- User Registration and Login
- Product Listing and Management
- Online Bidding System
- Auction Results and Winner Selection
- Payment Management
- User Chat System
- Admin Dashboard
- Fraud Alert Management

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Database
MySQL is used to store user details, product information, bids, auction results, payment records, chat messages, and fraud alerts.

## Installation
1. Download or clone this repository.
2. Install the required Python packages.
3. Configure the MySQL database using the provided SQL file.
4. Update the database connection settings.
5. Run the application using Python.
